About this project

E-Commerce Store is a full-stack demo storefront: an Angular single-page application in front of a live Express + MongoDB REST API, deployed on Vercel.

Features

  • Browse a live product catalog with search, category filters and sorting.
  • Product details pages with related products.
  • Full authentication flow: sign up, email confirmation, login, profile, and forgot/reset password.
  • Role-based admin area with a dashboard, product management (add, edit, delete) and user management.
  • Route guards protect the catalog and admin pages; toasts give feedback on user actions.

Tech stack

Frontend

Angular (standalone components, signals), Bootstrap 5, bootstrap-icons, ngx-sonner.

Backend

Node.js, Express, MongoDB with Mongoose, JWT authentication, Nodemailer.

How it fits together

This Angular app talks to the API over HTTPS. The API handles products, users, authentication tokens and confirmation emails.

Want the technical details? The backend lives in its own repository, and both deploy to Vercel.
